# Purpose

Real-system integration and browser verification.

# Ownership

This document owns this subtree.

# Local Contracts

Use dedicated test users, temporary fixtures and isolated listener ports. Never log passwords. Test the real server/PTY/filesystem rather than replacing it with mocks. Closure checks expect 404 for untouched terminals and archived metadata for used terminals; use a command or real accepted input when a fixture requires a retained closed archive. Terminal fixtures supply columns/rows and assert HTTP 201 before using session IDs. Systemd and Docker runtime checks require those facilities to be available.

# Work Guidance

Keep implementation and checks small and complete. Pure module fixtures that assert UI text must install the real catalog explicitly; never add a bundled production fallback just for tests. Copy GUI fixtures into the dedicated user's readable temporary directory; do not require traversal of the source checkout. Use lowercase Playwright letter keys for unshifted noVNC shortcuts (`Control+a`); uppercase letters cause X11 to synthesize Shift.
