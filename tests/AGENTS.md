# Purpose

Real-system integration and browser verification.

# Ownership

This document owns this subtree.

# Local Contracts

Use dedicated test users, temporary fixtures and isolated listener ports. Never log passwords. Test the real server/PTY/filesystem rather than replacing it with mocks. Systemd and Docker runtime checks require those facilities to be available.

# Work Guidance

Keep implementation and checks small and complete.
